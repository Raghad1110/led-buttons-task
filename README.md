# led-buttons-task
An Arduino-based project that controls three LEDs using three separate push buttons. Each button is assigned to one LED. When a button is pressed, the corresponding LED turns on for 3 seconds and then automatically turns off. This project demonstrates basic digital input/output handling with pinMode(), digitalRead(), and digitalWrite(),

# Project Overview

The “LED Buttons Task” involves creating a simple system where buttons control the on/off state of an LED. The system can be used as a learning tool for understanding basic microcontroller interfacing and GPIO (General Purpose Input/Output) functionality.

# Features:
 • Button Control: Buttons are used to toggle the state of the LED.
 • LED State Feedback: The LED turns on or off based on button presses.
 • Simple Hardware Setup: Minimal components required for the task.

# Technology Stack
 • Microcontroller: Any microcontroller with GPIO pins (e.g., Arduino, ESP32, etc.).
 • Components:
 • LED
 • Push Buttons
 • Resistors
 • Programming Language: C/C++ (for Arduino or similar microcontrollers).

 # Installation and Setup
 1. Hardware Setup:
 • Connect the button and LED to the microcontroller.
 • Use appropriate resistors for each component.
 2. Code Setup:
 • Clone the repository to your local machine:
git clone https://github.com/Raghad1110/led-buttons-task.git
• Open the project in your preferred IDE (e.g., Arduino IDE).
 • Upload the code to the microcontroller.

# How It Works
 • When the button is pressed, the state of the LED is toggled (on or off).
 • This project demonstrates basic GPIO usage with physical components.
